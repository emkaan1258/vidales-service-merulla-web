Extract the ZIP and open index.html in your browser. Keep index.html, style.css, script.js
and the images folder together. No installation or internet connection is needed.

Files
- index.html   Page markup (HTML)
- style.css    All styling (plain CSS, responsive: desktop, laptop, tablet, phone)
- script.js    Mobile menu + Services dropdown (plain JavaScript, no libraries)
- images/      plumbing.jpg, electrical.jpg, lawn-care.jpg, home-tech.jpg
               (cropped from the original home-services.png, which is kept as the
               full-size master but is no longer loaded by the page)
